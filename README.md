# JadeRoot Clinic — Dummy Multipage UI

Static client-demo UI for a traditional wellness / acupuncture clinic.

## Included
- Home
- About
- Treatments hub
- Acupuncture
- Cupping Therapy
- Moxibustion
- Herbal Consultation
- Reflex Therapy
- Herbal Catalogue + filters
- Product detail
- Appointment booking UI
- Contact
- FAQ accordion
- Privacy Policy
- Terms & Conditions

## Run
Open `index.html` directly, or use VS Code Live Server.

All content, prices, branding, images/placeholders and clinical copy are demo material.
Connect the appointment form, catalogue, WhatsApp, CMS/database, authentication and payment/order flow to the client's actual requirements.
